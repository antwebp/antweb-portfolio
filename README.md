# ANTWEB — портфолио-сайт веб-разработчика

Одностраничный сайт-визитка Антона Подгайного: презентует услуги фрилансера по разработке сайтов, Telegram-ботов, автоматизаций и AI-агентов, и собирает заявки от потенциальных клиентов.

## Задача

Классическая проблема фрилансера — заявки идут вразнобой через разные каналы (соцсети, сарафанное радио, биржи), а единой точки, которая продавала бы услуги и объясняла условия работы, не было. Сайт решает это:

- **Презентует экспертизу** — опыт, специализация, ключевые навыки.
- **Закрывает частые вопросы клиента до созвона** — сроки, стоимость, этапы оплаты, что происходит после запуска (блок FAQ).
- **Прозрачно показывает прайс** — конкретные вилки цен по каждой услуге, чтобы отсеивать нецелевые заявки.
- **Собирает лиды в один канал** — форма заявки на сайте отправляет имя и телефон напрямую в Telegram, без CRM и лишних шагов.

## Для кого

Малый и средний бизнес, который ищет исполнителя на разработку сайта, Telegram-бота, автоматизацию процессов или AI-агента и хочет работать напрямую с разработчиком, без посредников и агентств.

## Структура сайта

- **Hero** — заголовок, ключевое УТП, кнопка «Обсудить проект»
- **Обо мне** — бэкграунд (опыт в продажах → разработка), ключевые навыки
- **Портфолио** — карточки проектов (сейчас плейсхолдеры, наполняется по мере появления кейсов)
- **Услуги и стоимость** — 6 направлений с вилками цен: лендинг, многостраничный сайт, Telegram-бот, автоматизация, AI-агент, сопровождение
- **Как я работаю** — 5 этапов от заявки до запуска
- **FAQ** — частые вопросы о сроках, оплате, правках
- **Контакты** — форма заявки (имя + телефон) и ссылки на мессенджеры

## Стек

- HTML5, CSS3 (без фреймворков, кастомная вёрстка), vanilla JavaScript
- Google Fonts: Inter, Space Grotesk
- Скролл-анимации и прогресс-бар прочтения на чистом JS (`js/script.js`)
- Обработка формы заявки — PHP-скрипт (`send-lead.php`), отправляет данные в Telegram через Bot API
- SEO: `robots.txt`, `sitemap.xml`, Open Graph / Twitter Card метатеги

## Запуск локально

Статику можно открыть напрямую или поднять локальный сервер:

```bash
python -m http.server 8080
```

Форма заявки (`send-lead.php`) требует хостинг с поддержкой PHP — на голом статическом сервере (`http.server`, `npx serve`) запросы к ней работать не будут.

## Деплой

Требуется хостинг с поддержкой PHP (для обработки `send-lead.php`). Перед деплоем на публичный/новый хостинг вынести токен Telegram-бота и chat_id из `send-lead.php` в переменные окружения.
